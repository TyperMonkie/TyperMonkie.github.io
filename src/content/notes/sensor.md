请思考：上课的这间教室内有哪些传感器，请列举，至少5种，多多益善。
每种传感器，请列明：所检测的物理量、作用、基本原理和大致价格，可用表格，限一页纸。
|传感器|物理量|作用|基本原理|大致价格|
|---|---|---|---|---|
|烟雾传感器|烟雾颗粒（气溶胶微粒）浓度（颗粒物数量 / 遮光率）|监测环境烟雾，火灾早期预警，检测是否有燃烧产生的烟尘，触发报警信号|**光电式（最常见）**：内部发光二极管 + 光敏接收管。无烟时光照无法到达接收管；烟雾进入腔体，烟尘散射光线，光敏管收到光信号，判断烟雾超标。对阴燃火灾（闷烧、浓烟）更敏感。|模块版（DIY / 单片机，如 MQ-2）：5～20 元成品独立烟感报警器（家用电池款）：20～60 元工业 / 消防认证烟感（485 / 总线消防烟感）：80～200 + 元|
|指纹传感器（在咱们教室门口进门的地方）|指纹表面凹凸的**微观几何形态（脊线、谷线）**；电容式检测皮肤与传感器极板间**电容值**变化|采集人体指纹图像，提取指纹特征点，用于身份识别、开锁、权限核验，对比预存指纹判断是否匹配|**电容式（手机、门禁最常用）**：传感器表面大量微小极板。指纹凸起脊线接触极板，谷线位置存在空气；空气和皮肤介电常数不同，各处电容不一样，以此采集指纹凹凸纹路。体积小、识别快。**光学式（考勤机、打卡锁）**：LED 光源照射手指，指纹脊线反光强、谷线反光弱，CCD/CMOS 接收反射光，形成指纹图像。成本低，但是容易受手指脏污、干手指影响。|指纹模块（AS608，单片机 DIY）：25～60 元独立光学指纹头（考勤机用）：15～40 元手机内置超声波指纹模组：几十～上百元（批量价）成品指纹锁整套：300 元起|
|温湿度传感器|温度 (℃)、相对湿度 (% RH)|监测教室温度、湿度，联动空调 / 风扇，保证教室舒适环境|DHT11：热敏电阻测温度，湿敏电容测湿度；湿度变化会改变电容值，电路转换成数字信号输出。|DIY 模块：3～15 元；智慧教室成品变送器：60～180 元|
|声音传感器|声音响度（分贝 dB）|麦克风采集声波|核心元件是**驻极体麦克风（咪头）**。声波是空气的疏密振动，传到麦克风振膜上，推动振膜来回振动。振膜和背板之间有一层永久带电的驻极体薄膜，振膜振动会改变振膜与背板之间的**电容大小**。电容变化就会产生微弱的变化电信号（模拟电压）。|模块：5～20 元；专业噪声变送器：100～300 元|
|线性霍尔传感器（在磁轴键盘上）|磁场磁感应强度 B（特斯拉 T），间接测量磁铁距离、按键位移|检测磁轴按键的按压深度；判断按键按下 / 松开，支持自定义触发行程、快速触发 RT，无物理触点，寿命长|基于**霍尔效应**：通电半导体薄片，在垂直磁场作用下，载流子发生偏转，薄片两侧产生霍尔电压。磁轴轴心内置永磁铁；按下按键，磁铁向下靠近 PCB 上的霍尔传感器，**磁感应强度变大，霍尔电压随之线性变化**。主控采集电压，换算磁铁距离（按键行程），软件设定阈值判定按键触发。|单颗霍尔芯片：0.5～3 元；TMR 芯片：2～8 元；整套成品磁轴键盘：200～1000 元 +|
|2.4G 无线接收模块（USB 接收器）（老师的ppt翻页笔）|无线电信号强度|接收翻页笔发来的无线指令，传给电脑|翻页笔按下按键后，单片机把 “上一页 / 下一页” 编码成数字信号，调制到 2.4GHz 无线电波向外发射。USB 接收器天线接收同频率电磁波，解调还原出数字指令，通过 USB 口传给电脑；电脑系统把指令识别成键盘按键（PgUp/PgDn），PPT 就翻页。|接收器单模块：3～10 元；整套翻页笔（笔 + 接收器）：20～80 元|
