# 欢迎来到我的笔记空间

这里是一篇 **Markdown 示例笔记**。以后只需要把 `.md` 文件放进 `src/content/notes/`，网站就会自动读取标题、日期、分区与正文。

## 可以使用的内容

- 标题与多级标题
- **粗体**、*斜体*和链接
- 有序或无序列表
- 引用、代码块与行内代码

> 记录不一定要宏大。把当下想清楚的一点留下来，就已经很有价值。

```js
const idea = 'write it down'
console.log(idea)
```

这是起点，之后可以直接替换成真正的日常、技术记录或心得。
