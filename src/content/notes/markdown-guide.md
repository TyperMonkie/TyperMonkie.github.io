# 如何添加一篇新笔记

在 `src/content/notes/` 中新建一个 `.md` 文件，并在文件顶部填写下面的信息：

```md
---
title: 我的文章标题
date: 2026-09-15
category: 技术
summary: 一句话介绍这篇文章。
---

# 正文标题

从这里开始写正文。
```

保存后，开发页面会自动刷新。新的 `category` 会自动出现在左侧分区里。

也可以点击左侧的“导入 Markdown”，临时预览电脑中的 `.md` 文件。本地导入不会上传到服务器，刷新页面后会消失。
